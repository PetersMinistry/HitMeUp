# Thunderbird Listing Text

## Short Description

Set reminders on emails so important follow-ups never get lost.

## Full Description

HitMeUp Reminder adds simple, reliable reminders directly inside Thunderbird so important emails do not slip through the cracks.

Set a reminder on any message and return to it at the right time—whether it is a follow-up, reply, deadline, or task.

## Features

- Set reminders from the right-click menu or toolbar.
- Quick presets: test, 1 hour, 1 day, or custom date/time.
- Clean dashboard with Due and Active reminders.
- Search active reminders instantly.
- Open, edit, or cancel active reminders.
- Snooze or dismiss reminders with one click.
- Open the original email directly from reminders.
- Toolbar badge shows active and due reminder status.

## Email Integration

- Optional: mark emails unread when reminders become due.
- Optional: move emails back to Inbox when reminders become due.
- Applies a `HitMeUp Reminder` tag to tracked messages.
- Supports multiple Thunderbird accounts safely.

## Privacy

HitMeUp Reminder runs entirely inside Thunderbird.

- No external data transmission.
- No analytics or tracking.
- All reminders are stored locally.

## Permissions

Permissions are used only to support reminder features such as opening emails, updating message state when enabled, applying reminder tags, storing settings, and displaying notifications.
