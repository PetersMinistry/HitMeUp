# Thunderbird Listing Text

## Short Description

Set reminders on emails so follow-ups do not get lost.

## Full Description

HitMeUp Reminder adds simple, reliable reminders directly inside Thunderbird so important emails do not slip through the cracks.

Set reminders on any message and come back to it at the right time, whether it is a follow-up, response, or task.

## Features

- Set reminders from the right-click menu or toolbar.
- Quick presets: test, 1 hour, 1 day, or custom date/time.
- Clean dashboard with Due and Active reminders.
- Search active reminders quickly.
- Open, edit, or cancel active reminders from the active list.
- Snooze or dismiss reminders with one click.
- Open the original email directly from reminders.
- Toolbar badge shows reminder status at a glance.

## Email Integration

- Optional: mark emails unread when reminders become due.
- Optional: move emails back to Inbox when reminders become due.
- Applies a `HitMeUp Reminder` tag to tracked messages.
- Works safely across multiple accounts.

## Privacy

HitMeUp Reminder runs entirely inside Thunderbird.

- No data is sent externally.
- No tracking or analytics.
- All reminders are stored locally.

## Permissions

Permissions are used only to support reminder functionality such as opening emails, updating message state when enabled, applying reminder tags, and displaying notifications.
