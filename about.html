HitMeUp Reminder

Set reminders on emails so follow-ups do not get lost.

Version 1.0.4 Author: Peter Moreno Local-first

Overview

HitMeUp Reminder adds simple, reliable reminders directly inside Thunderbird so important emails do not slip through the cracks.

Set reminders on any message and come back to it at the right time, whether it is a follow-up, response, or task.

Features

  • Set reminders from the message-list right-click menu.
  • Use quick presets: test, 1 hour, 1 day, or custom date/time.
  • Review Due and Active reminders from the toolbar dropdown.
  • Search active reminders quickly.
  • Open, edit, or cancel active reminders from the Active list.
  • Snooze or dismiss reminders with one click.
  • Open the original email directly from reminders.
  • See reminder status at a glance with the toolbar badge.

Email Integration

  • Optionally mark emails unread when reminders become due.
  • Optionally move emails back to Inbox when reminders become due.
  • Apply a red HitMeUp Reminder tag to tracked messages.
  • Update the existing reminder when the same email is reminded again.
  • Work safely across multiple accounts.

Privacy

  • No data is sent externally.
  • No tracking or analytics are used.
  • All reminders are stored locally inside Thunderbird.
